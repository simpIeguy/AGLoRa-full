# Прошивка трекера «Поиск БЛА»

Прошивка GPS-трекера с радиомодулем LoRa: трекер раз в 30 секунд отправляет по радио свои координаты, принимает координаты других трекеров и передаёт всё на телефон по Bluetooth в приложение «Поиск БЛА».

## Железо

- Плата Seeed Studio XIAO ESP32-C3.
- LoRa EBYTE E32-433T30D (433 МГц).
- GPS Matek M10Q (u-blox M10).

Пины, мощность, интервал и имя трекера — в `src/settings/settings.h`.

## Сборка и прошивка (PlatformIO)

Окружение указывать всегда: по умолчанию в `platformio.ini` стоит другая плата.

```bash
pio run -e ebyte-e32-esp32-c3-seeed-xiao
```

```bash
pio run -e ebyte-e32-esp32-c3-seeed-xiao -t upload
```

Перед прошивкой задать имя трекера в `settings.h` (`NAME` и `BLE_NAME`, одинаковые): `UAV1`…`UAV9` для трекеров на БЛА, `GROUND1`…`GROUND9` для людей. По этому имени приложение делит трекеры на группы.

Перед включением к LoRa-модулю должна быть подключена антенна.
